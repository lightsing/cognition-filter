# 用户使用手册

欢迎使用 **认知滤网（Cognition Filter）**。本手册详细介绍安装启动、模型配置、规则编写、网页日常操作、站点插件管理、过滤统计以及常见问题的排查方法。

---

## 1. 安装与启动

### 1.1 获取与运行

- **发布版（推荐日常使用）**：确保 `cognition-filter.exe` 与同级目录的 `plugins/` 文件夹（内含 `cf_site_bilibili.dll`、`cf_site_x.dll` 等）放在一起，双击 `cognition-filter.exe` 即可后台运行。
- **开发调试版**：在源码根目录运行 `.\start.ps1`，会自动执行快速 `dev` 构建并带控制台日志窗口启动。

启动成功后，Windows 任务栏右下角通知区域（托盘）会出现 **认知滤网** 漏斗图标（如未直接显示，请点击通知区域左侧的 `^` 展开隐藏图标）。

### 1.2 系统托盘操作

| 操作 | 功能 |
| --- | --- |
| **双击托盘图标** | 直接在浏览器中打开本地 WebUI「配置」页 |
| **右键 → 修改配置** | 打开模型接口、API Key、并发与插件管理页面（`/settings`） |
| **右键 → 打开配对页** | 打开站点油猴脚本安装与配对口令页面（`/`） |
| **右键 → 过滤统计** | 打开实时过滤与 token 消耗统计页面（`/stats`） |
| **右键 → 退出** | 优雅关闭本地 Agent，并立即保存尚未落盘的统计增量 |

> **提示**：同一数据目录同时只运行一个实例。若重复双击 `cognition-filter.exe`，新进程会检测到已有实例正在运行并自动退出。

### 1.3 WebUI 界面与多语言

WebUI 的「配置」「过滤规则」「过滤统计」「配对」四个页面共用顶部导航栏。右上角可随时切换 **简体中文** 与 **English**，首次访问自动跟随浏览器语言，偏好保存在浏览器的本地存储中。

## 2. 配置模型服务

首次启动后，必须先配置视觉大模型的 API Key 才能开始过滤：

1. 打开 WebUI 的「**配置**」页面。
2. 填写 **模型服务地址**（默认 `https://api.deepseek.com`）、**模型名称**（默认 `deepseek-flash`）与 **API Key**。
3. 点击保存。

### 注意事项

- **接口兼容性**：Agent 会在模型服务地址后自动追加 `/chat/completions`，支持 DeepSeek 官方接口以及任何兼容 **图片输入（多模态）** 和 **JSON 输出** 的 OpenAI 风格接口。外部服务地址必须使用 `HTTPS`，本机服务（`127.0.0.1`、`localhost`、`[::1]`）允许使用 `HTTP`。
- **密钥保护与留空规则**：API Key 保存在本机 `%LOCALAPPDATA%\CognitionFilter\runtime.json`。为减少暴露，配置页仅提示密钥是否已设置；后续修改其他选项时，API Key 输入框留空并保存会沿用现有密钥。
- **平滑切换**：在配置页更换模型、地址或密钥后，当前正在进行中的判定会正常完成，随后自动切换到新配置。
- **环境变量初始化**：仅在首次运行（尚无 `runtime.json`）或从旧版配置迁移时，Agent 会读取 `COGNITION_API_KEY`、`DEEPSEEK_API_KEY`、`COGNITION_MODEL`、`COGNITION_API_BASE` 初始化配置文件；之后的启动直接读取本地配置文件。

## 3. 安装脚本与完成配对

1. 在浏览器中安装 [Tampermonkey（篡改猴）](https://www.tampermonkey.net/) 扩展。
2. 右键托盘图标 →「**打开配对页**」。
3. 点击对应站点的「**安装或更新脚本**」按钮（例如「安装或更新 哔哩哔哩首页」或「安装或更新 X 首页时间线」），在油猴安装页面点击确认。
4. 复制配对页展示的 **本机配对口令**。
5. 用自己的账号打开目标网站首页（[B 站首页](https://www.bilibili.com/) 或 [X 首页](https://x.com/home)）并刷新，在页面弹出的配对对话框中粘贴口令即可生效。

### 配对与升级说明

- **重新打开配对弹窗**：若误关了首次配对弹窗，可在目标网站点击浏览器工具栏的 Tampermonkey 图标，在脚本菜单中选择「**配对本地 agent**」。
- **端口自动发现**：Agent 默认监听 `127.0.0.1:17321`，遇到冲突时会自动切换至 `49152–65535` 内的候选端口。脚本（0.4.0+）会自动寻找并通过加密质询验证已配对的 Agent，**无需修改脚本或重新配对**。
- **脚本更新**：升级 Agent 或站点 DLL 后，若页面或托盘提示脚本有新版，请始终通过托盘打开的**本机配对页**点击更新链接，避免从非预期端口下载脚本。升级后已有配对自动保留。

## 4. 站点插件管理

在 WebUI 的「**配置 → 插件管理**」中，你可以独立管理每个网站的插件：

- **启用 / 禁用站点**：禁用后，Agent 停止接收该站点的新送审请求（已接收的会正常完成）。以 B 站脚本 0.5.1+ 为例，脚本会在下次同步（切回标签页或前台每 30 秒轮询一次）时自动撤掉所有遮盖；重新启用后自动恢复。禁用状态保存在 `disabled-plugins.json` 中，重启后依然有效。
- **调整站点并发**：可在站点卡片中单独调整该站的「浏览器送审并发（`browserConcurrency`）」与「封面下载并发（`coverConcurrency`）」，也可一键恢复 DLL 默认值。
- **B 站自动「内容不感兴趣」**：在 B 站站点卡片中，可按需开启「**对被过滤的视频自动点击『内容不感兴趣』**」（默认关闭，需 B 站脚本 0.6.0+）。开启后，命中规则的视频会自动向当前登录的 B 站账号提交原生内容反馈，帮助驯化推荐算法；若卡片缺少对应菜单入口，仍会保留本地遮盖。
- **更新与新增站点**：
  - **更新**：用新版 DLL 覆盖 `plugins/` 目录下的同名文件，在插件管理点击该站点的「**重新加载**」即可热切换（若新 DLL 校验失败，会自动回退继续使用旧版）。如果脚本逻辑也有更新，点击「安装或更新脚本」并刷新网页。
  - **新增**：将新站点的 DLL 放入 `plugins/` 目录，点击「**发现新插件**」即可加载。

## 5. 编写与管理过滤规则

在 WebUI 顶部的「**过滤规则**」页面（或在网页油猴菜单点击「**编辑规则**」），你可以全面定制过滤策略。

### 5.1 规则组结构

最多可配置 **24 组** 规则，每组包含：

- **规则名称**：命中卡片遮罩上展示的提示标签。
- **适用范围**：可选「**全局**」（对所有已启用站点生效）或限定于**单个站点**（例如仅对 `bilibili` 或 `x` 生效）。
- **组开关**：一键启用或停用整组规则。
- **命中要点（Include）**：逐条描述希望屏蔽的内容特征，支持单条编辑、启用或禁用。
- **保留例外（Exclude）**：逐条描述容易被误杀、但希望放行的例外特征，支持单条编辑、启用或禁用。

> 点击「**保存规则**」后，受影响站点的模型前缀缓存会自动重新预热，浏览器页面在下次同步时立即按新规则生效。

### 5.2 内置默认规则

首次启动时内置 3 组开箱即用的规则：

1. **政治相关**（全局）：过滤以政治人物活动、政党、选举、政治制度、政府决策、公共政策或地缘政治为主题的内容；保留虚构剧情、普通办事流程或个人故事中顺带提及的内容。
2. **鼓吹对立相关**（全局）：过滤煽动群体敌意、贬低站队、拼贴编号评论渲染群体淘汰焦虑等内容；保留中性报道、核查反驳、劝和或就事论事的政策解释。
3. **网帖、问答和评论截图转视频**（仅 B 站）：过滤问句标题配满屏文字叙事、网帖/留言截图或社交平台评论搬运类视频；保留网站教程、实拍字幕、原创讲义或偶尔引用网帖的独立讲解。

### 5.3 规则编写最佳实践

- **写可观察的视觉与文本特征**：模型只能看到卡片的标题/正文、作者昵称和封面/配图，看不到视频正片或音轨。规则应聚焦于「封面/标题里能直接看出来的线索」，而不是「视频第 3 分钟讲了什么」。
- **善用「保留例外」缩小误杀**：当某类规则容易误伤正常科普、反驳或吐槽时，不要删掉规则，而是把该类正常特征写入同组的「保留例外」。
  - 示例命中要点：`问句标题搭配占满封面的个人回答截图`
  - 示例保留例外：`偶尔引用网帖的独立讲解`
- **善用单条启停做实验**：不确定某条新规则是否过于宽泛时，可先单独启用测试，效果不理想时一键禁用该条，无需删除重写。

## 6. 网页交互与反馈闭环

### 6.1 卡片状态说明

| 状态 | 视觉表现 | 说明 |
| --- | --- | --- |
| **跳过（原生保留）** | 保持网站原样 | B 站首页广告位与直播间、X 首页广告与非首页页面由脚本本机识别并直接跳过（讨论广告或直播的普通视频仍会正常判定）。 |
| **待检测** | 不透明占位遮罩 | 卡片刚进入页面或封面正在懒加载中；接近视口的卡片优先排队送审。 |
| **已放行** | 正常显示 | 全部启用规则均未命中。 |
| **已命中（屏蔽）** | 30px 高斯模糊 + 命中规则名称 | 至少命中一组启用规则。 |
| **待判定（异常/证据不足）** | 保持遮盖并显示具体原因 | 封面无法获取、模型判定证据不足、或网络/接口超时。可恢复错误会自动退避重试，也可通过油猴菜单手动重试。 |

### 6.2 临时查看与「反馈误杀」

1. 在被高斯模糊遮盖的卡片上点击「**仍要查看**」展开原内容。
2. 展开后如需操作：
   - **X 帖子**：点击帖子右上角「`…`」菜单。
   - **B 站卡片**：打开卡片的推荐反馈菜单（缺少原生菜单入口的卡片会直接在展开后显示操作按钮）。
3. 可选择：
   - **重新遮盖**：恢复该卡片的模糊遮罩。
   - **反馈误杀**：请本地 Agent 调用模型分析误判原因，自动向对应命中组补充一条可编辑的「保留例外」，并在界面展示分析说明与实际写入的要点。

### 6.3 主动屏蔽漏网卡片

如果你在首页看到了不想看但未被规则拦截的卡片：

1. 点击浏览器 Tampermonkey 菜单 →「**选择卡片进行屏蔽**」。
2. 将鼠标移动到目标卡片上，确认高亮框选正确后点击（随时按 `Esc` 键退出选卡模式）。
3. 在弹窗中：
   - **归入已有规则组**：Agent 调用模型分析漏判特征，自动为所选组补充一条「命中要点」，提交后立即按新规则重新筛选。
   - **新建规则组**：点击「**前往 WebUI 编辑规则**」创建并保存新组，再返回原卡片归入新组（选卡流程新建的组默认限定于当前网站）。

## 7. 过滤统计与用量监控

打开 WebUI 的「**过滤统计**」页面（每 5 秒自动刷新），可在「**本次运行**」与「**累计**」之间切换查看：

- **屏蔽率**：`已屏蔽 / (已屏蔽 + 已放行)`。同一卡片命中多组规则时，总屏蔽数只计 1 次，同时分别计入各命中规则组的统计。
- **本地判定缓存命中**：直接复用 24 小时内存缓存、未发起模型请求的次数与命中率。
- **前缀命中率**：模型响应中报告的缓存命中 token 除以总输入 token，涵盖送审、规则预热与反馈分析。
- **纠错统计**：分别记录成功应用的「反馈误杀」与「手动选卡屏蔽」次数。
- **各网站用量**：按站点插件 ID 独立展示送审、预热、本地缓存命中率、模型前缀命中率及输入/输出 token 数（同一网站的多个标签页合并计算；旧版本升级前的历史数据归入「升级前（未区分网站）」）。

> 累计统计持久化在数据目录的 `statistics.json` 中（仅存计数、站点和规则 ID，不含任何卡片内容）。运行期间每 5 秒检查变更并保存，正常退出时再落盘一次；强制结束进程可能丢失最后 5 秒内的增量。

## 8. 常见问题（FAQ）

### Q1：点击托盘图标没反应，或程序启动失败？
- 检查是否已有另一个同数据目录的实例在运行（查看任务栏隐藏图标）。
- 若提示端口全部被占用，说明首选端口 `17321` 及 32 个高位候选端口均不可用，请释放占用端口后重试。

### Q2：首页卡片一直显示遮盖，无法放行？
- 首先确认已在 WebUI「配置」页填写了有效的 **API Key**，且余额/额度充足。
- 查看卡片遮罩上的提示原因：若是「未取得封面」或「跨域读取超时」，可能是网络较慢或图片 CDN 暂时异常；若是「模型请求失败 / 429」，请检查模型服务商限流状态，或在配置页适当调低 `modelConcurrency`。
- 如需临时恢复原网页浏览，可在 WebUI「配置 → 插件管理」中先禁用对应站点插件。

### Q3：为什么 B 站和 X 的规则互不影响，但有些规则两边都生效？
- 每组规则都可以设置为「全局」或指定单个站点。默认情况下，「政治相关」与「鼓吹对立相关」为全局规则，「网帖/问答/评论截图转视频」仅对 B 站生效。你可以在「过滤规则」页自由调整每组的适用站点。

### Q4：为什么看到有「预热调用（warmupCalls）」产生 token 消耗？
- 使用 DeepSeek 等支持 KV Cache 的接口时，Agent 会预先将当前站点启用的规则发送一次作为共享前缀，后续每张卡片判定都能复用该前缀缓存，从整体上显著降低输入 token 成本。预热本身由模型服务端按正常规则计费，连续 2 小时未使用或修改规则后才会再次预热。

### Q5：如何备份或迁移我的规则与配置？
- Windows 默认数据目录为 `%LOCALAPPDATA%\CognitionFilter`（也可通过环境变量 `COGNITION_FILTER_DIR` 自定义）。
- 备份其中的 `rules.json`（规则与反馈样本）、`runtime.json`（模型与并发配置，**含明文 API Key，切勿公开分享**）、`statistics.json`（累计统计）和 `disabled-plugins.json`（禁用站点列表）即可完成迁移。
