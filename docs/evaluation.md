# B 站首页过滤实测

2026 年 11 月 22 日，使用 DeepSeek 官方接口的 `deepseek-flash` 和 `bili-card-9` 提示词。精简版要求模型先为每张卡写不超过十个字的可见依据，再输出命中的全部规则编号。Rust 端向页面返回命中类别。每批最多四张，图片用低分辨率，关闭思考模式。对照版使用同一批卡片、规则和模型，只替换提示词。

总 token 采用 API 返回的输入和输出之和，本次减少 15.9%。43 张中有 22 张带封面，其余测试标题判断和规则例外。生产模式会把无法取得封面的卡片留在待判定状态。评分需要完整标签集一致，额外标签、漏报标签和未决状态均计入评判。五张用户卡参与了提示词校准。样本量不足以估计整个账号信息流的准确率。

Rust 客户端另行调用真实模型，五张用户卡均符合标注。钓鱼回答、汽车对话和单条评论封面命中截图转视频，中考分流同时命中截图转视频与鼓吹对立，小费泛化命中鼓吹对立。

本轮三项偏差都在无图的基础组。模型误拦了核查地域冲突的视频和引用知乎回答后实拍验证的视频，并放行了一条预期应待判定的空泛标题。运行账户首页的统计按处理次数累计，刷新与重判可能重复计数。

误杀与漏放也分别进行了真实模型调用。钓鱼实拍对照得到“个人经历问句配真人户外实拍，缺少回答或评论截图线索”这一保留条件。中考分流卡得到“编号网友观点与跨年人数骤减比较渲染分流焦虑”这一命中条件。两次验证使用测试配置。运行中的规则由编辑器及实际提交的反馈更新。
