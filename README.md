# 认知滤网（Cognition Filter）

**认知滤网（Cognition Filter）** 是一款本地优先的多模态网页内容过滤工具，通过「**本地 Rust Agent + 站点 DLL 插件 + 油猴（Tampermonkey）脚本**」的协作架构，结合视觉大模型对信息流推荐卡片进行自然语言语义筛选，帮你屏蔽不想看到的内容。

与传统的关键词黑名单不同，认知滤网能同时理解卡片的**标题/正文、作者昵称与封面/配图**，并采用**先遮盖、后判定**的机制，在卡片进入视口前完成视觉遮罩，避免不愿看到的内容闪现。

---

## 核心特性

- **多模态语义过滤**：综合分析标题、正文、作者昵称与封面/配图，支持用自然语言编写「命中要点」与「保留例外」，精准区分立场、呈现形式与题材。
- **先遮盖、后判定**：推荐卡片出现时先以不透明占位遮盖，靠近视口的卡片优先排队送审，明确放行后才展示；命中规则的卡片显示 30px 高斯模糊与命中规则名称。
- **人机协同的规则自进化**：支持在页面上直接「**反馈误杀**」或「**选择卡片进行屏蔽**」，由模型自动反思误判/漏判原因，为对应规则组生成可编辑的保留例外或命中要点。
- **可扩展的站点插件体系**：每个网站封装为独立的原生 DLL 插件（内含站点清单、页面策略与油猴脚本），支持在 WebUI 中按站点启用、禁用、发现新插件与热重载。
- **前缀缓存预热与精细并发**：使用 DeepSeek 等支持上下文缓存的接口时，按站点独立预热「全局规则 + 本站规则」前缀，大幅降低重复 token 消耗；支持站点级和全局并发限流与 HTTP 429 自动退避。
- **本地优先与隐私保护**：Agent 仅监听 `127.0.0.1`，账号 Cookie 始终留在浏览器中，API Key 与规则仅保存在本机数据目录；脚本与本地服务间采用 HMAC-SHA256 质询-响应完成自动端口发现与安全配对。
- **内置 WebUI 与实时统计**：提供简体中文 / English 双语管理界面，一站式完成模型配置、规则编辑、插件管理、脚本配对与多维度用量统计。

## 内置支持站点

发布包默认随附两个站点插件 DLL：

| 站点插件 | 插件 ID | 适用页面 | 提取内容与特性 |
| --- | --- | --- | --- |
| **哔哩哔哩首页** | `bilibili` | B 站桌面首页推荐流 | 标题、UP 主昵称、封面缩略图（优先页面缓存读取，失败时可回退至本地 Agent 备用下载）；自动跳过广告与直播间；可选对命中卡片自动点击「内容不感兴趣」。 |
| **X 首页时间线** | `x` | X（Twitter）「为你推荐」与「正在关注」 | 作者、页面可见正文（最多 8,192 个 UTF-16 单元）、最多 4 张配图或视频静态预览缩略图；支持纯文字帖；自动跳过广告与非首页页面。 |

> X 与 B 站各自拥有独立的站点专属规则、前缀预热、并发配置、判定缓存与用量统计。开发者也可基于 C ABI / Rust SDK 为更多网站编写插件，详见 [站点插件开发指南](docs/site-plugins.md)。

## 快速开始

### 1. 启动本地 Agent 并配置模型

1. 双击发布版 `dist/release/cognition-filter.exe` 启动本地服务。
2. 在 Windows 任务栏通知区域找到 **认知滤网（Cognition Filter）** 漏斗图标（可能在隐藏图标列表中）。
3. **双击图标**或右键选择「**修改配置**」，在 WebUI 中填写模型服务的 API Key（默认兼容 DeepSeek `deepseek-flash`，也可配置其他支持图片输入和 JSON 输出的 OpenAI 兼容接口）并保存。

> 首次打开 WebUI 时会自动跟随浏览器语言，右上角可随时切换 **简体中文 / English**。

### 2. 安装对应站点的油猴脚本

1. 确保浏览器已安装 [Tampermonkey（篡改猴）](https://www.tampermonkey.net/) 扩展。
2. 右键托盘图标，选择「**打开配对页**」。
3. 点击需要使用的站点（如「**安装或更新 哔哩哔哩首页**」或「**安装或更新 X 首页时间线**」），在 Tampermonkey 弹窗中确认安装。
4. 首次安装时，复制配对页显示的 **48 位本机配对口令**。

### 3. 在目标网站完成配对

1. 使用你的账号打开 [B 站首页](https://www.bilibili.com/) 或 [X 首页](https://x.com/home) 并刷新页面。
2. 在首次弹出的配对窗口中粘贴刚才复制的本机配对口令并确认。
3. 配对成功后，首页推荐卡片即刻开始按规则自动筛选。

> 如误关弹窗，可随时从浏览器 Tampermonkey 扩展菜单中点击「**配对本地 agent**」重新打开。升级 Agent 或脚本时会自动沿用已有配对，端口变动时脚本也会自动重新发现已配对的本地服务。

## 日常使用速览

- **编辑规则**：在 WebUI「**过滤规则**」页面（或油猴菜单「编辑规则」）中管理规则组。每组可设为「全局」或限定于单个网站，并可逐条编辑、启用或禁用「命中要点」与「保留例外」。内置初始规则覆盖：政治相关（全局）、鼓吹对立相关（全局）、网帖/问答/评论截图转视频（仅 B 站）。
- **处理命中卡片**：命中规则的卡片会以 30px 高斯模糊遮盖并显示命中的规则名。点击「**仍要查看**」展开后，可通过帖子/卡片反馈菜单选择「**重新遮盖**」或「**反馈误杀**」。
- **主动屏蔽漏网卡片**：在油猴菜单选择「**选择卡片进行屏蔽**」，鼠标悬停高亮目标卡片后点击（按 `Esc` 退出），将其归入已有规则组或前往 WebUI 新建规则组。
- **查看过滤统计**：右键托盘选择「**过滤统计**」或在 WebUI 顶部切换至统计页，实时查看本次运行与历史累计的屏蔽率、本地缓存命中率、模型前缀命中率及各网站 token 消耗。
- **退出程序**：发布版右键托盘图标选择「**退出**」即可优雅关闭并落盘统计数据。

更详细的操作说明与故障排查请参阅 [用户使用手册](docs/user-guide.md)。

## 项目结构

```text
cognition-filter/
├── src/                    # 本地 Rust Agent 核心代码与内置 WebUI 资源
│   ├── main.rs             # 入口：单实例锁、端口监听、插件发现、托盘与优雅退出
│   ├── config.rs           # runtime.json 加载、环境变量初始化与配置校验
│   ├── rules.rs            # 规则组与反馈样本存储、版本指纹计算
│   ├── model.rs            # 多模态视觉模型调用、封面处理、429 退避与解析
│   ├── plugins.rs          # DLL 站点插件加载、校验、热重载与脚本注入
│   ├── ports.rs            # 127.0.0.1 候选端口序列与实例文件锁
│   ├── tray.rs             # Windows 系统托盘图标、右键菜单与更新气泡
│   ├── service.rs          # Axum HTTP 路由、鉴权中间件、逐卡调度与缓存
│   ├── service/            # 发现配对、反馈纠错、插件管理、设置与统计子模块
│   └── *.html / *.js / *.css # 内置双语 WebUI（配对、设置、规则、统计）
├── sdk/                    # 站点插件 SDK（Rust 宏、C 头文件 cf_site.h、公共 JS 客户端）
├── plugins/                # 内置站点插件源码
│   ├── bilibili/           # 哔哩哔哩首页插件（DLL + site.json + bilibili.user.js）
│   └── x/                  # X 首页时间线插件（DLL + site.json + x.user.js）
├── config/                 # 编译期内置默认配置（default-rules.json、prompts.json、runtime.json）
├── eval/                   # 提示词对照评测脚本、测试样本集、封面与历史报告
├── test/                   # 浏览器端到端回归测试与插件测试夹具
├── docs/                   # 项目完整文档
├── build.ps1               # 工作区一键构建与插件打包脚本
└── start.ps1               # 开发期快速构建并启动脚本（带控制台日志）
```

## 开发与验证速查

前置要求：**Rust 1.91+**（Edition 2024，见 `rust-toolchain.toml`）、**Node.js 22+**（用于浏览器回归测试与提示词评测）。

```powershell
# 开发模式快速构建并运行（带控制台输出）
.\start.ps1

# 仅构建 Dev 版 / 构建 Release 分发包
.\build.ps1
.\build.ps1 -Release -OutputDirectory dist/release

# 运行 Rust 单元测试与严格静态检查
cargo test --workspace
cargo clippy --workspace --all-targets -- -D warnings

# 运行浏览器回归测试与离线评测样本校验
node --test test/userscript.test.mjs
node --test test/settings.test.mjs
node eval/compare.mjs --suite eval/holdout.json
```

更多开发与实测细节见 [开发、测试与评测指南](docs/development.md)。
