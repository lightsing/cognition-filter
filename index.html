为什么不是关键词屏蔽

真正读懂封面与语境的四重机制

关键词正则无法分辨「制造对立」与「理性辟谣」，也看不见封面上满屏的聊天与回答截图。认知滤网从呈现机制到规则进化全面重构过滤体验。

先遮盖，后判定 · 零闪屏护眼盾

卡片进入 DOM 瞬间施加不透明占位，靠近视口的卡片优先排队送审，明确放行后才显露内容。封面懒加载期间（最多等待 5 秒）不占送审并发名额，证据不足或超时的卡片保持待判定，绝不「先闪现再隐藏」。

document-start 注入 30px 高斯模糊 节点复用世代校验

标题、昵称与封面联合判断

合看标题/正文、作者昵称和缩略图（X 支持最多 4 张配图与视频海报），自然语言编写「命中要点」与「保留例外」，一眼区分实拍科普与网帖截图搬运。

误杀反思与选卡屏蔽闭环

展开命中卡片点击「反馈误杀」，或通过油猴菜单「选择卡片进行屏蔽」，模型会自动提炼可泛化的视觉与文本边界，生成可编辑的例外或命中要点写入规则组。

按站点前缀预热 + 三级缓存与并发调度

使用 DeepSeek 等兼容接口时，Agent 为每个启用站点独立预热「全局 + 本站规则」KV Cache 前缀，逐卡判定从规则确认轮次直接分叉；叠加 24 小时 1,024 条内存判定缓存与页面缓存读图，大幅压低 Token 成本与网络延迟。

三步开启清净浏览

从下载到完成配对，只需 3 分钟

  1. 01

    启动 Agent 并填写密钥

    下载并解压 Release 压缩包，运行 cognition-filter.exe。双击任务栏托盘漏斗图标打开配置页，填入 DeepSeek 或任意兼容视觉模型的 API Key。

  2. 02

    安装站点油猴脚本

    在浏览器安装 Tampermonkey，右键托盘选择「打开配对页」，点击安装「哔哩哔哩首页」或「X 首页时间线」脚本，并复制 48 位本机配对码。

  3. 03

    刷新首页粘贴配对码

    打开 B 站或 X 首页并刷新，在首次弹窗粘贴本机配对码即可开始过滤。支持随时在网页内点击「反馈误杀」或「选卡屏蔽」持续调优。
